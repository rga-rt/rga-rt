#### Featured project

**[claude-nuxt-fullstack-scaffold](https://github.com/rga-rt/claude-nuxt-fullstack-scaffold)** — a Claude Code skill + plugin that scaffolds production-ready Nuxt 3 apps (Tailwind, Vitest, ESLint; optional i18n, SQLite/Drizzle, or Supabase). Ships three runnable, CI-tested examples and installs straight from the plugin marketplace:

```bash
/plugin marketplace add rga-rt/claude-nuxt-fullstack-scaffold
/plugin install nuxt-fullstack-scaffold@claude-nuxt-scaffold
```
